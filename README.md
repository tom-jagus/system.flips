# FLIPS - Fleeting Logic for Inbox Processing System

FLIPS is a documentation-first email operating model for users who want less distraction, clearer triage, and stronger mailbox hygiene.

The system uses:

- fixed folder structure with numbered ordering
- focused email time blocks (instead of constant checking)
- automation based on sender groups and deterministic routing
- cleanup rules that keep temporary areas temporary

- `new_ideas/` - exploratory notes and drafts

## Principles

- `Inbox` is for immediate attention, not storage.
- `00 Awaiting triage` is the default fallback queue.
- Keep temporary work in `01 Reply later` and `02 Aside pile`.
- Keep long-term records in `03 Paper trail`.
- Use automation to reduce noise, not hide decisions.
- Run the first email block at the start of the workday.
