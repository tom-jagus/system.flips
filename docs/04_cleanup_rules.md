# Cleanup Rules

Cleanup keeps FLIPS usable over time.

The goal is simple: temporary folders stay temporary, records stay intentional.

## Cadence

| Cadence | Focus areas | Expected outcome |
| --- | --- | --- |
| Every email block | `Inbox`, `00 Awaiting triage`, `01 Reply later` | no passive accumulation |
| Daily wrap-up | `02 Aside pile`, `04 Events` | active context stays current |
| Weekly | `05 Notifications`, `06 Newsletters`, stale discussions | remove low-value volume |
| Monthly | `03 Paper trail` quality sweep | retain only meaningful records |
| Quarterly | deep paper trail review | remove outdated or duplicate records |

## Folder-specific cleanup behavior

### `Inbox`

- Keep only immediate-attention messages.
- Route or clear items during each email block.

### `00 Awaiting triage`

- Treat as a short-lived queue.
- Drain consistently during scheduled blocks.

### `01 Reply later`

- Reply at the next feasible block.
- Move to `02 Aside pile/01 discussions` only when waiting on external response.

### `02 Aside pile`

- `01 discussions`: max 10 days, follow up every 2 days.
- `02 action context`: keep only while related atomic todo is active.
- `99 attachments to keep`: clear after attachment is moved to permanent storage.

### `03 Paper trail`

- Keep records for retrieval value, not habit.
- Remove duplicates and low-value copies.
- Prefer one clear record over multiple near-identical threads.

### `04 Events`

- Remove after event completion unless record value justifies moving to `03 Paper trail`.

### `05 Notifications` and `06 Newsletters`

- Prune regularly.
- Strong suggestion: remove items older than 10-30 days unless still useful.

## Cleanup decision questions

For any message you keep, ask:

- Why am I keeping this?
- What folder best reflects that reason?
- When should this message leave this folder?

If no clear answer exists, delete or re-triage.

## Anti-patterns and corrections

| Anti-pattern | Correction |
| --- | --- |
| Keeping old newsletters by default | apply 10-30 day pruning window |
| Using `02 Aside pile` as archive | move record items to `03 Paper trail` or delete |
| Keeping unknown senders unresolved | decide sender now, then remove `Unknown sender` |
| Preserving everything in `03 Paper trail` | keep only messages with retrieval value |
